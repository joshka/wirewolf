# wirewolf documentation

Start with the [project README](../README.md) for what wirewolf is and how to install it.

- [User guide](guide.md): how wirewolf models your network, reading verdicts, configuration,
  the CLI and TUI, speed tests, the AI brief, and troubleshooting
- [Deploying](deploy.md): Docker, sign-in, reverse proxies, and who can see and change what
- [CLI reference](cli.md): every command and flag, generated from `--help`
- [API](api.md): the JSON and server-sent events API
- [Dashboard](ui.md): the dashboard's pages, and developing it

[dev/](dev/) holds design history and development notes: the original design
([dev/design-v1.md](dev/design-v1.md)), the dashboard's design language and framework decision,
and how parallel work is integrated. They describe how wirewolf got here, not how to use it.
